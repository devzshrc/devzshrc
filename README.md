## What I've been building

### <img src="https://yc.devzshrc.in/logo.svg" width="28" height="28" alt="" /> Orbiter (YC Jobs)

A job search app that brings listings from several sources into one place. Choose your preferences, compare jobs with your resume, and track your applications.

- Personalised job feed and daily picks with match explanations.
- Job search with filters for location, remote work, and other requirements.
- Saved jobs, application stages, notes, and follow-up reminders.

**Built with:** Bun, React, Tailwind CSS, PostgreSQL, Drizzle, and Cloudflare Workers.

[Try it](https://yc.devzshrc.in) · [Code](https://github.com/devzshrc/yc) · [Build notes](https://devzshrc.in/work/yc-jobs)

### <img src="https://app.devzshrc.in/icon.svg?v=2" width="28" height="28" alt="" /> Docks

A workspace for reviewing GitHub pull requests. It helps reviewers follow changes and keep track of reviews across repositories.

- AI review guides and questions about a pull request.
- Side-by-side diffs, inline comments, and saved review progress.
- Team permissions, reviewer assignments, and background jobs for GitHub updates.

**Built with:** Next.js, React, Hono, tRPC, PostgreSQL, Drizzle, OpenAI, and Cloudflare Workers.

[Try it](https://app.devzshrc.in) · [Code](https://github.com/devzshrc/docks) · [Build notes](https://devzshrc.in/work/docks)

### <img src="https://notyourtypeformx-web.vercel.app/icon.svg" width="28" height="28" alt="" /> Schema

An AI form builder. Describe the form you need and get an editable draft with questions, field types, validation, and rules for skipping questions.

- Generate a form from a plain-language prompt.
- Edit the generated questions and rules.
- Validate AI output against a typed schema before showing it in the editor.

**Built with:** Next.js, tRPC, Express, Drizzle, and Zod.

[Try it](https://notyourtypeformx-web.vercel.app) · [Code](https://github.com/devzshrc/notyourtypeformx) · [Build notes](https://devzshrc.in/work/schema)
